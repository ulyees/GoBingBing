# GoBingBing

[![test](https://github.com/ulyees/GoBingBing/actions/workflows/test.yml/badge.svg)](https://github.com/ulyees/GoBingBing/actions/workflows/test.yml)
[![license: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

**打不开就换一个。** 一个面向 Chrome / Edge 的 Manifest V3 扩展：当 Google 打不开时自动改用 **cn.bing.com**，当 cn.bing.com 打不开时自动改用 **bing.com**，并尽量保留搜索词。

弹窗会检测每条规则里**来源域名**的延迟，用「来源图标 → 箭头 → 替换图标」展示每条规则的当前状态：哪些站点现在打不开、会被替换成哪个站点。

## 功能

- **自动故障转移**：主框架加载失败（DNS 失败、连接重置、超时等）时，按规则跳到备用搜索引擎；搜索页会带上关键词。
- **来源延迟检测**：打开弹窗时，对每条规则的**来源域名**（不是替换目标）发起轻量探测，显示可访问性和毫秒延迟。可在设置中关闭，或把超时设为「自动」——自动模式参考该域名上次的延迟，在 1.5–8 秒间调整。
- **一眼看懂规则**：弹窗里每条规则显示为「域名 + 延迟 + 来源图标 → 箭头 → 替换图标 + 域名」，图标紧贴箭头，箭头直接连接来源与替换站。箭头颜色与线型随探测结果变化：绿色实线表示来源可达，琥珀色虚线表示部分可达，红色虚线表示全部不可达、访问时会触发切换。
- **站点图标**：优先使用已缓存的图标字节，其次站点自己的 favicon，再其次 DuckDuckGo 图标代理，最后回退到带品牌色的首字母。某次成功拿到真实图标后会写入本地缓存，下一次打开弹窗直接使用。
- **搜索词迁移**：Google 的 q 会带到 Bing；图片搜索 tbm=isch 会落到 Bing 图片频道；非搜索页回到目标首页。其他引擎（百度 wd、搜狗 query）也可配置。
- **防循环**：每个标签页记录切换链，A→B 后不会立刻 B→A；超过连续跳转上限时停止并提醒，避免 A⇄B 死循环。
- **手动切换**：弹窗一键切换当前页；即使没有匹配规则，只要页面带有搜索词，也能直接用 Bing 搜索该词。
- **可编辑规则**：增删、排序、启停、导入导出，支持 * 通配符。
- **最近记录 / 通知 / 角标 / 深色模式**。

## 安装

1. 打开 Chrome 的 `chrome://extensions`，或 Edge 的 `edge://extensions`。
2. 打开「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择**包含 manifest.json 的项目根目录**。
4. 首次安装会自动打开设置页；之后点击工具栏的 GoBingBing 图标打开弹窗。

需要 **Chrome / Edge 102 或更高版本**（Manifest V3、模块化 Service Worker、chrome.storage.session）。

扩展是纯静态文件，没有构建步骤，也不需要安装依赖。

## 使用

### 弹窗

| 区域 | 说明 |
| --- | --- |
| 顶部开关 | 暂停 / 恢复自动切换，与设置页共用同一份配置。 |
| 当前页面 | 当前域名、命中的规则、当前会发生的动作。 |
| 主按钮 | 有匹配规则时显示「切换到 <目标域名>」；没有规则但有搜索词时显示「用 Bing 搜索」。 |
| 切换规则 | 每条规则的来源、来源延迟、指向箭头、替换目标；当前页命中的规则会高亮。 |
| 最近记录 | 最近的自动切换、手动切换、中止事件，最多显示 6 条。 |

打开弹窗后探测才会开始；关闭弹窗不会在后台持续探测。探测是可选的，关闭后规则仍然显示图标和静态信息，只是没有延迟与箭头状态。

### 箭头状态

| 状态 | 外观 | 含义 |
| --- | --- | --- |
| 检测中 | 灰色、呼吸动画 | 探测请求尚未返回。 |
| 可访问 | 绿色实线箭头，附「正常」 | 该规则的所有来源域名都可访问，**现在不会**触发切换。 |
| 部分可达 | 琥珀色虚线箭头，附「部分」 | 多来源域名中只有部分可达；只有不可达的那个来源会触发切换。 |
| 打不开 | 红色虚线箭头，附「切换」 | 所有来源域名都探测失败，访问时会切换到右侧目标。 |
| 未检测 | 灰色 | 检测功能已关闭，或规则没有可解析的来源域名。 |
| 已停用 | 整行变淡 | 规则被关闭，不参与自动匹配。 |

> 延迟是探测耗时，不是搜索引擎的完整加载时间，仅用于判断「现在大致能不能连上」。

### 图标

图标的获取顺序：

1. 本地缓存的图标字节（需要曾经获得站点权限并成功下载）；
2. 本地缓存过的图标 URL；
3. 站点自身的 favicon；
4. DuckDuckGo 图标代理；
5. 全部失败时显示首字母，背景色由域名哈希决定。

当某次探测成功、且你已授予该来源站点权限时，扩展会顺便下载图标字节并持久化；弹窗中的图标会立即刷新，后续打开也直接命中缓存。图标缓存最多保留 40 个域名。

### 手动切换

- 命中规则：跳到规则目标，并按规则决定是否保留路径 / 查询参数。
- 没有命中规则、但 URL 有搜索词（q、wd、query、keyword、text、p，含 #q=）：用 Bing 搜索该词。
- 两者都没有：按钮禁用。

## 规则

在设置页「切换规则」中编辑。规则**从上到下匹配，命中第一条即生效**。

| 字段 | 说明 |
| --- | --- |
| 启用 | 关闭后该规则不参与匹配，也不参与探测。 |
| 名称 | 只用于展示。 |
| 来源域名 | 多个域名用逗号、中文逗号或空格分隔。支持通配符。 |
| 切换目标 | 完整的 http(s) 地址，可带路径。 |
| 保留原路径与查询参数 | 勾选后把原 URL 的 path / query / hash 接到目标上，适合镜像站。 |

通配符规则：

| 写法 | 匹配 |
| --- | --- |
| `google.*` | google.com、google.com.hk、google.co.jp 等 |
| `*.example.com` | example.com 本身及其所有子域 |
| `*` | 任意域名（谨慎使用） |
| `cn.bing.com` | 仅该域名 |

不勾选「保留原路径」时，目标这样计算：

- 原 URL 有搜索词 → 目标站点加上对应参数（Bing / 多数引擎用 q，百度用 wd，搜狗用 query）；
- 原 URL 是 Google 图片搜索（tbm=isch）→ Bing 的 /images/search；
- 没有搜索词 → 目标站点首页。

默认规则：

1. `google.*`、`www.google.*` → `https://cn.bing.com`
2. `cn.bing.com` → `https://www.bing.com`（保留路径与查询参数）

把规则列表清空并保存，就等于**关闭自动切换**，只保留手动按钮。

### 配置备份

设置页底部可导出 / 导入 JSON（文件名 gobingbing-settings.json），或恢复默认规则。

## 高级选项

| 选项 | 默认 | 说明 |
| --- | --- | --- |
| 重复事件抑制 cooldownMs | 3000 ms | 同一次失败在短时间内被上报多次时只处理一次。 |
| 单标签页最多连续跳转 | 4 | 超过后停止并提醒，防止循环。 |
| 导航前连通性预检 | 关闭 | 访问受规则管理的站点前先发 HEAD；失败立刻切换。Google 较慢但能打开时可能误判，故默认关闭。 |
| 预检超时 | 2500 ms | 预检请求的超时。 |
| 弹窗来源检测 | 开启 | 打开弹窗时探测来源域名。 |
| 来源检测超时 | 自动 | auto 按上次延迟调整（1.5–8 秒），也可固定 2/4/8/12 秒。 |

预检和图标字节缓存需要读取目标站点内容，因此需要可选站点权限。设置页「高级选项 → **授权规则中的站点**」会一次性申请所有来源域名与替换目标对应的 https://host/* 权限。

## 权限与隐私

| 权限 | 用途 | 是否必需 |
| --- | --- | --- |
| webNavigation | 监听主框架导航失败与 chrome-error:// 错误页。 | 必需 |
| storage | 保存设置、最近记录、标签页切换链、延迟与图标缓存。 | 必需 |
| notifications | 自动切换 / 中止时发系统通知。 | 必需（可在设置中关闭通知） |
| alarms | 数秒后清除工具栏角标。 | 必需 |
| 可选站点权限 https://*/* | 预检、下载图标字节。 | **可选**，只在点击授权时申请 |

扩展没有账号、没有遥测、不会上传设置或浏览记录。数据都保存在本机 chrome.storage.local / chrome.storage.session。图标代理会向 DuckDuckGo 请求 host 对应的图标；如果不希望产生这个请求，可以只使用站点自身 favicon 或首字母回退（见 [PRIVACY.md](PRIVACY.md)）。

## 工作原理

1. webNavigation.onErrorOccurred 捕获主框架加载失败，忽略用户取消产生的 net::ERR_ABORTED。
2. 部分版本失败表现为 chrome-error:// 页面而不触发上述事件，此时用 onCommitted + 该标签页最后一次主导航 URL 兜底。
3. 读取设置，先尝试解包 Google 的 /url?q= 跳转链接；再按域名顺序匹配规则。
4. 用该标签页的切换链去重、限制跳转次数、识别 A⇄B 往返；命中循环时停止。
5. chrome.tabs.update 跳到目标，并写入记录、通知、角标。
6. 弹窗打开时，对每条启用规则的具体来源域名（如 google.* → google.com）发 HEAD 请求到 /favicon.ico?gbb=...，mode: "no-cors"、禁止缓存，按设置超时（自动或固定 2/4/8/12 秒）；据此显示延迟和箭头状态。

标签页切换链存放在 chrome.storage.session，浏览器关闭后自动清空，Service Worker 休眠不会丢失。

## 目录结构

~~~text
manifest.json             扩展清单（MV3）
src/
  background.js           Service Worker：失败检测、规则匹配、跳转、记录、预检
  popup.html/.css/.js     工具栏弹窗：当前页、来源检测、规则箭头、图标、记录
  options.html/.css/.js   设置页：规则编辑、检测选项、权限授权、导入导出
  lib/
    url-utils.js          URL 解析、域名通配、搜索词提取、目标 URL 计算
    rules.js              默认规则、规则查找与校验
    settings.js           默认值、规范化、存储、事件日志
    state.js              单标签页切换链（session storage + 内存兜底）
    probe.js              来源域名探测、超时策略、延迟缓存
    icons.js              图标候选、首字母回退、图标字节缓存
    chrome-helpers.js     chrome.* 回调 API 的 Promise 封装
icons/                    16 / 32 / 48 / 128 图标
tools/make_icons.py       用 Pillow 重新生成图标
tests/                    Node 单元测试
~~~

## 已知限制

- 只处理**主框架导航失败**；子 iframe 失败被忽略。
- 页面已经打开、但内容被拦截或显示空白时，不算网络错误，不会自动切换；请用弹窗的手动切换。
- net::ERR_ABORTED 视为用户取消（点击链接、按 Esc 等），不触发切换。
- 弹窗检测只探测**来源域名**，不探测替换目标；目标是否可达由你点击时或浏览器实际访问时决定。
- 探测是 no-cors 的 HEAD 请求，只能判断网络层是否可达，无法读取 HTTP 状态码；服务器拒绝 HEAD 时可能被标记为「打不开」。
- 浏览器报告错误到扩展跳转之间有一小段延迟；这是事件驱动的固有限制。
- 同一标签页短时间内反复失败会触达跳转上限，这是有意的防循环保护。

## 版本与迁移

当前版本 **2.0.0**。2.0 将扩展更名为 GoBingBing，新增来源延迟检测、规则箭头、图标缓存与检测设置；存储键与 1.x 兼容，升级不会丢配置。

- 1.0.x → 1.1.0：若 Google 规则仍是默认值（目标为 www.bing.com），会自动改成 cn.bing.com；手动改过目标的规则不会被动。
- 1.1.x → 2.0.0：新增设置项使用默认值，原有规则、记录保留。

完整记录见 [CHANGELOG.md](CHANGELOG.md)。
